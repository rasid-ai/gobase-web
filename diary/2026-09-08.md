### Decisions

- **Jira holds features; `specs/` holds what was built; ADRs and `context/`
  hold the information.** The only gate is the PR, and it is not treated as
  a gate. Rejected keeping HLR ids as labels with the enforcement dropped —
  full removal was chosen. `diary/` and `docs/adr/` keep their old
  references because both are append-only.

- **`apps/map/catalog.py` is the only module that knows `kb` tables and
  columns.** Raw SQL through `connections["kb"]`, not unmanaged Django
  models. Metadata has no fixed field set, the coverage test is
  PostGIS-specific, and this keeps `KB_APP_LABELS` empty so the router's
  refusal to write or migrate `kb` stays absolute.

- **Every `kb` read filters `status = 'active'`.** Superseded and failed
  assets stay in the table. The `(modality, status)` index exists for this.

- **No tests for this slice**, by the user's call. The point-in-coverage
  query cannot be tested as CI stands: the service is plain `postgres:16`
  with no PostGIS, and the `kb` alias is `TEST: {"MIRROR": "default"}`.

- **Basemap is OpenStreetMap.** This conflicts with
  `context/design-system.md`, which says basemaps pair with the theme
  (Positron-class light, dark for dark). Standard OSM has no dark variant.

- **`terra-draw` not installed.** Drawing is a later feature; an unused
  dependency is worse than a missing one.

### Problems solved

- **The footprint never drew, with no visible failure.** MapLibre rejected
  the layer: `fill-color: color expected, "oklch(...)" found`. Design tokens
  are authored in oklch, which MapLibre's parser does not read. Fix in
  `mapTokens.ts`: paint one pixel on a canvas with the token value and read
  the channels back. Setting `fillStyle` and reading it back does **not**
  work — Chrome returns the oklch string unchanged.

- **Three route tests failed with `window.matchMedia is not a function`**
  after the real Map page replaced the placeholder. jsdom does not
  implement `matchMedia` and the token hook called it. Guarded it.

- **`pnpm build` failed on a missing module after renaming an OpenAPI
  `operationId`.** Orval deleted the old generated model file but left its
  export in `src/api/generated/model/index.ts`. Orval does not prune that
  index, and the CI drift check would not have caught it.

### Open threads

- Local fixture data is three raster assets sharing one extent, so grouping
