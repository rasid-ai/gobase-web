# UI Registry

Which components exist and what they match. One component, one line —
history belongs in the diary, reasoning in an ADR (guarded by /imprint).

| Component | Matches |
|---|---|
| `ui/Button` | Flat, hairline, zero shadow, radius `--radius`. Variants: primary (emerald fill, near-black text), outline, ghost, link. Sizes sm/md/lg. `asChild` for link buttons. |
| `ui/Input` | h-10, `bg-input`, hairline border, `--ring` focus ring; `aria-invalid` turns the border and ring destructive. |
| `ui/Label` | Radix label, 14px medium, paired with an `Input` by `htmlFor`. |
| `ui/Alert` | Inline form-level error. Destructive hairline border on a 10% destructive tint. No icon, no shadow. |
| `PortalWordmark` | GEO + emerald PORTAL, 14px bold, tracking 0.1em. The header identity mark on every page. |
| `LandingPage` | Unauthenticated root. Header, hero + decorative map graphic, three capability cards, footer. Mono micro-labels. No API calls. |
| `SignInPage` | Centered 380px column, mono eyebrow, hairline card, RHF + Zod, inline `Alert` on failure. |
| `AppShell` | Authenticated frame: header, Atlas/Assets/Data Governance nav, mono identity chip, theme toggle, sign out. Every link owns its whole subtree for the active highlight. |
| `ui/Badge` | Status pill: token tinted 15% behind the token as text, radius-full. A dot precedes the label — disc for live states, ring for inert ones, so colour never carries the meaning alone. Tones: success/running/failed/queued/neutral. |
| `ui/Dialog` | Radix dialog. Hairline border on `bg-popover`, no shadow, overlay is `bg-background/80` with a 2px blur. Title, description, right-aligned footer. |
| `ui/Skeleton` | Pulsing `bg-muted-foreground/10` block for a data view that has not answered. |
| `RunsPage` | Data Governance: page header with relative last-read, Refresh, and Admin-only Run pipeline. Status filter chips, then rows in a hairline panel sharing one grid so run and step badges align; a row expands in place. Load more keeps the pages it has. Explicit empty, filtered-empty, loading, and pipeline-unreachable states. |
| `RunLogs` | Event log behind a disclosure inside an opened run, fetched only when asked for. Mono rows: time, level, step key (column always reserved so messages align), message. Minimum-level chips default to info and report how many lines are hidden; error rows expand to a stack. |
| `ui/Toast` | Transient failure notice, bottom-centre, `aria-live="polite"`. Hairline destructive border on a 10% tint like `Alert`, plus a Close control; self-dismisses after 6s. `Alert` stays the inline, in-place version. |
| `AssetDetailPanel` | One asset's metadata: mono data type, then Expand (icon-only outline, `aria-expanded`), Draw and Clear as outline buttons on one row, the asset name as a 14px medium heading, then a hairline definition list of the plain values. Structured values are held back behind a `text-primary` "N more fields · Expand" link; expanded, the pane widens to `min(48rem, 100% - 2rem)` and each follows as a mono micro heading over a `MetadataValue` table. Draw becomes Redraw once the asset is on the map, and a spinner while it loads. |
| `DrawArea` | The polygon tool, live only in draw-area mode; renders nothing itself. terra-draw draws with the `--map-selection` token (converted to hex by `mapTokens.hex`, since the tool takes nothing else) at 0.15 fill and a 2px outline. A finished polygon is handed up and cleared from the tool; the page then outlines it as its own source — `--map-selection`, 0.08 fill, 2px line, drawn above the data layers — so the area survives leaving the mode. A refused click (over 100 corners, or edges crossing) raises a `ui/Toast` saying which. |
| `Clear area` | Outline-style mono button beside the mode switch, shown only while an area is drawn. Same hairline border and `bg-background/95` as the switch it sits next to. |
| `LayersPanel` | The layers drawn on the map, docked bottom-left. Hairline panel, mono header with a count and Clear all; one row per layer with a visibility checkbox, truncatable name, count of features in the current view or drawn area (`+` when there are more than the budget read, `—` when it could not be read; the tooltip says which scope) and remove. The truncation note on an asset row says "zoom in for the rest" for a view and "draw a smaller area for the rest" for a drawn area, because zooming does nothing to an area. Renders nothing when empty. |
| `PlaceSearch` | Go to a place or a coordinate, docked under the mode switch. One box for both — two numbers are a coordinate, anything else is searched for. Mono micro-label, `Go` outline button, inline `Alert` on a bad value with `aria-invalid` on the field; place candidates in a `ui/Combobox` popup beneath. |
| `AssetsPage` | The catalog: filter rail left, card grid right, in two modes. Header keeps the title Assets (a dataset's label once one is open, under a `text-primary` "All datasets" back link) with the count beside it in the mono micro style (data chrome, like the rail's counts); the sort select shows only when assets are listed. Numbered pages under the asset grid, and a grid dims rather than empties while the next answer is read. While a question is active (Semantic) the body in either mode is `PassagesBody` and the count reads "N documents", no sort. Asset cards are `AssetCard`. Explicit loading, empty, filtered-empty and error states for datasets and assets alike. |
| `AssetFilters` | The Assets rail: a `ui/Segmented` Datasets / Assets switch on top, then the search group — one field whose label and placeholder follow the search kind and the level (dataset names, asset metadata, places with the geocoder's list under it, or a question: a three-row `textarea` in a hairline `rounded-md` box on `bg-input` whose own foot holds a mono "⏎ to search" hint and an outline sm Search button, the box taking the focus ring as a whole; Enter sends, Shift+Enter breaks a line); under it a deliberately quieter Metadata / Places / Semantic switch than the mode switch: a `role=radiogroup` of three 28px `rounded-md` icon radios (TextSearch, MapPin, Sparkles; chosen `bg-primary/15 text-primary`, the other `text-muted-foreground` with a foreground hover), names as `title` tooltips and aria labels, and choosing one focuses the field; then the filters it set as removable chips: hairline `rounded-md`, a mono kind label (Place; Semantic; Metadata only while on another kind), the value truncated with the whole as its `title`, a muted ✕. Then mono group labels, checkbox rows per data type with mono counts (only once assets are listed and no question is active), radio rows for the ingestion window, and a Clear all filters ghost button that appears only once a filter is set. Data types are rendered from the API, never from a list held here. |
| `ui/Pagination` | Numbered page control for an offset-paged list. Previous and Next as outline buttons either side of square page numbers — the current one filled, the rest ghost — with `…` where numbers were left out. Renders nothing for a single page. |
| `ui/Combobox` | A text box that offers options beneath it, hand-rolled on the ARIA 1.2 pattern: focus stays in the input and `aria-activedescendant` moves. Hairline `bg-popover` panel, no shadow, `z-20`; mono section label, two-line rows — name in body text, coordinate in mono — and a neutral `muted-foreground/10` highlight. Messages sit outside the listbox, so none can be arrowed onto. |
| `PlaceOptions` | What a place search shows: the `PLACES` label and its rows, or one line for searching, nothing found, failed, and unavailable. |
| `ui/Segmented` | One choice of a few, side by side: `role=radiogroup` of `role=radio` buttons in a hairline, `rounded-md` strip. Chosen is `bg-primary/15 text-foreground`, the rest `text-muted-foreground` with a foreground hover. Body text for navigation choices; `mono` (11px uppercase, tracked) for data choices such as data types. The map's mode switch predates it and keeps its own `map-footprint` tint. |
| `SemanticPane` | The Atlas right pane in Semantic mode, same chrome as `AssetPane`. A `<form>` on top: mono micro-label "Describe what you are looking for", an h-9 `ui/Input` beside an outline `Search` button (disabled while blank). Under it a mono "Matches · N" label and `AssetRow`s with the dataset named in the micro line (`Airports · document · pdf`) and, for a document, a mono `Open` (`OpenPdf`) beside Draw — two actions, no more — then the usual detail panel on select. Muted one-line states: nothing asked yet, "Semantic search is unavailable.", "Nothing matches that."; three `Skeleton` rows while loading; `Failed` with Try again otherwise. |
| `OpenPdf` | A text button that opens a document's PDF in a new tab (`features/catalog/openDocument.ts`): opens the tab inside the click, fetches the bytes with the session, points the tab at an object URL — with `#page=N` when given a page. Waits while fetching; a failure closes the tab and shows a `text-xs text-destructive` "Could not open the PDF" beside the button. The look is the caller's (`className`), the text too (`label`), and an optional `icon` follows the text (an `ArrowUpRight` where it opens at a page). |
| `AssetCard` | One asset as the catalog lists it, hairline on `bg-card`, `rounded-lg`: mono data type and format across a divided top, dataset label `text-xs text-muted-foreground` (hidden inside that dataset), name 14px medium `wrap-anywhere`, the parser's title under a document's name, mono 11px id, "topic · size" (page count for a document), optional `children` edge to edge between the body and the foot (a list of rows, not a paragraph), then a divided foot with the mono ingestion date and text-link actions (`OpenPdf`, Locate on map) in `text-primary`. Shared by the browse grid and `PassagesBody`. |
| `PassagesBody` | The deep search's answer on the Assets page, from the Claude Design pass of 2026-11-03: one column of `AssetCard`s at most 960px wide, one per matching document, best first, each with a `divide-y` list of passage rows edge to edge between its body and its foot. A row (`px-3.5 py-3`) reads across an 88px mono gutter — "p. 3" / "pp. 3–4" over the chunk type — then a muted `text-xs` heading path joined with › and the text `line-clamp-3`, with a muted chevron pinned to the row's top-right corner; `hover:bg-accent/50`, expanded `bg-accent/30`, the focus ring inset. The button is the gutter, heading and text (`aria-expanded`); expanded, the whole text shows, mono page buttons stand in the gutter when the passage spans pages (`h-6` hairline, chosen `border-primary bg-primary/15 text-primary`, labelled "Page N"), "Open PDF at p. N" with an arrow follows the text in the card's link style and opens at the previewed page, and a `PagePreview` takes a right column (34%, at most 300px). No scores anywhere. States: three card-shaped skeletons (strip, title, three gutter rows, foot); 503 → the page's centred hairline box "Semantic search is unavailable" (no retry); other failures → the same box with "The catalog could not be loaded." and an outline Try again; nothing → "No passages match that question" ("… in this dataset …" inside one). |
| `PagePreview` | One page of a document's PDF rendered by the server with the passage marked (`GET …/pages/{page}.png?chunk=`), fetched with the session into an object URL, shown as an `<img>` on a `bg-card` hairline `rounded-md` frame with `p-1.5` — paper on a mount — and a full alt ("Page 3 of <name>, passage highlighted"). The frame holds a Skeleton (`aspect-[1/1.3]`) while loading and a `text-sm text-destructive` "Could not render the page" on failure. The highlight itself is drawn server-side in the brand emerald (`apps/catalog/pages.py`), a token cannot reach it. |
| `AssetPane` | The Atlas right pane: `bg-background/95` with backdrop blur, hairline, `rounded-lg`, `p-4`, 22rem wide. Datasets level: mono count label, an h-9 `ui/Input`, then rows as hairline `rounded-md` buttons — label in body text, mono count right, mono type counts beneath — with a `map-footprint/60` hover. Files level: mono ChevronLeft "Datasets" back control, the dataset label as a 14px medium heading, the search, a mono `ui/Segmented` of All plus each type with its count, then asset rows (name, mono type · format, Draw). Skeleton rows while loading, a muted line plus outline Try again on failure, and a mono "N of M · search to narrow" past 200. |
| `MetadataValue` | Any metadata value, shaped by the value: text for plain values and lists of plain values, a hairline `rounded-md` table for objects (key / value rows, key as a row header) and lists of objects (one column per key). Mono 12px cells, `px-2.5 py-1.5`, rows split by `border-border`; headers are mono micro labels on `bg-muted/50`. Nested values nest tables; wide tables scroll inside their frame. Never raw JSON. |
| `DatasetCard` | A dataset on the Assets page, built like an asset card: whole card is a button, hairline on `bg-card`, `rounded-lg`, `hover:border-primary/60`. Mono type counts across a divided top, then the readable label (14px medium), the raw name in mono 11px muted, and a divided foot with the asset count and a `text-primary` Open. |
| `PageBoundary` | Wraps each page inside the shell, keyed by path. A render error shows an inline `ui/Alert` — "This page could not be shown.", the error message in mono 11px muted, and an outline Reload — instead of blanking the app; going to another page starts a fresh one. |
